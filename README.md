# School Safety Alert

Crie um aplicativo mobile chamado "Rede de Segurança Escolar - Escola".

Este aplicativo será usado exclusivamente por escolas cadastradas para enviar alertas de emergência para autoridades.

Objetivo:

Permitir que diretores ou responsáveis autorizados enviem rapidamente alertas de segurança para órgãos cadastrados.

Funcionalidades:

- Tela de login da escola.

- Cadastro da instituição.

- Tela inicial com botão grande e destacado:

"ENVIAR ALERTA DE EMERGÊNCIA"

Ao criar um alerta:

- Selecionar tipo de ocorrência:

  - Ameaça de segurança

  - Invasão

  - Emergência médica

  - Incêndio

  - Outro

- Campo para descrição da situação.

- Capturar localização automaticamente.

- Registrar data e horário.

- Mostrar confirmação antes do envio.

Após enviar:

- Mostrar mensagem "Alerta enviado com sucesso".

- Mostrar status:

  - Aguardando resposta

  - Equipe acionada

  - Atendimento iniciado

  - Encerrado

Criar histórico das ocorrências enviadas.

Design:

Interface simples, rápida e profissional.

Priorizar facilidade de uso em momentos de emergência.
